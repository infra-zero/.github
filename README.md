# .github

Source for the [InfraZero organization profile page](https://github.com/infra-zero).

Edit [`profile/README.md`](./profile/README.md); it goes live on push to `main`.

The repo name (`.github`) and that file path are both load-bearing, and the repo
must be public. There is no config and no alternative location — rename either
and the profile page silently goes blank, with no warning anywhere in the UI.
