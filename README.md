# .github

Source for the [InfraZero organization profile page](https://github.com/infra-zero).

GitHub renders an org profile from **`profile/README.md` in a public repo named
exactly `.github`**. Both the repo name and the file path are load-bearing —
rename either and the profile page silently goes blank.

Edit [`profile/README.md`](./profile/README.md); it goes live on push to `main`.
